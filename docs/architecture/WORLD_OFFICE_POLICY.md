# Brain AI Command World Office Policy
Version: 1.0
Status: APPROVED
Type: Architecture Decision Record (ADR)

---

# Purpose

This document permanently defines the visual direction of Brain AI Command World.

This policy exists to prevent future development from drifting into
fantasy RPG or medieval city designs.

The World project is a visualization layer only.

It must always represent the headquarters of Brain AI Trading System.

---

# Permanent Direction

Brain AI Command World SHALL be designed as a modern office building.

NOT

- fantasy city
- medieval kingdom
- village
- castle
- magic world
- MMORPG map

Instead the world represents

Brain AI Headquarters

# World Behaviour

The office is alive.

Employees

walk

sit

type

attend meetings

drink coffee

watch monitors

go to server room

return to desks

When trading events happen

Execution agent walks to Trading Desk.

Risk agent goes to Risk Office.

CEO enters Meeting Room.

Journal agent updates reports.

Recovery agent goes to Recovery Center.

Everything is visualization only.

---

# Trading Engine Separation

World NEVER controls trading.

World NEVER sends orders.

World NEVER changes risk.

World NEVER changes strategy.

World ONLY reads state.

Trading Engine remains authoritative.
