# Isometric Office World assets (W-ISO-2 / W-ISO-3)

All images under `assets/world/iso/` are generated by `world/scripts/generate_iso_assets.py` (drawing code in `world/scripts/iso_art.py`)
from `world/data/assets/iso_assets.json` using Pillow drawing primitives.

- No third-party art, models, textures or text were used or copied.
- DeskRPG (https://github.com/dandacompany/deskrpg) was used only as a UX reference; none of its
  code or assets are included.
