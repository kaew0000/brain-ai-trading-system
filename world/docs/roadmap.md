# Development Roadmap

1. **W1** — Architecture, schemas, lore skeleton, docs (documentation only).
2. **W1A** — Materialize folder structure and placeholder files in-repo (this phase).
3. **W2** — Design the read-only ingestion adapter (still no engine changes).
4. **W3** — Static scene rendering with placeholder shapes, pick a renderer.
5. **W4** — Asset pipeline activation (LPC sprites, tilesets, audio).
6. **W5** — Live data wiring (read-only) from real engine logs.
7. **W6** — Full UI panel implementation (minimap, inspectors, feeds).
