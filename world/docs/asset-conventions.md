# Asset Conventions (world/) — Reserved for Phase W4

- Character sprite sheets will follow the LPC (Universal LPC Spritesheet)
  layout convention: rows per direction, columns per animation frame.
- Standard animation set per character: `idle`, `walking`, `working`,
  `celebration`, `emergency`.
- Standard equipment slots: `head`, `body`, `weapon`, `accessory`, `aura`.
- No binary asset files are added in Phase W1/W1A — folders exist as
  placeholders (`.gitkeep`) only.
