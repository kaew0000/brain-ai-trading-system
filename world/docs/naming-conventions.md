# Naming Conventions (world/)

- District/character ids: lowercase kebab-case (e.g. `risk-fortress`, `bastion`).
- Schema files: `<name>.schema.json`.
- Sample files: `<name>.sample.json`.
- Lore files: one markdown file per entity, named after its id.
- Agent references inside character definitions use the existing uppercase
  agent name exactly as used in the trading engine (e.g. `PRIMUS`, `BASTION`).
